# s21_string+

Реализация собственной версии стандартной библиотеки string.h на языке C, с поддержкой форматирования (sprintf) и расширенными функциями обработки строк.

## Описание проекта

В рамках проекта реализованы основные функции библиотеки string.h, а также частично реализован sprintf. Реализация ведётся без использования стандартной библиотеки string.h (внутри основной логики), с соблюдением POSIX-совместимости, стиля кодирования Google и принципов структурного программирования. Также добавлены функции, вдохновлённые методом String из языка C#.

## Технологии
 - Язык: C (C11)
 - Компилятор: gcc / clang
 - Тестирование: Check
 - Покрытие кода: gcov, lcov
 - Сборка: Makefile
 - Стиль: Google C Style

## Реализованные компоненты

### 1. Базовые функции (string.h)

Реализовано 15+ функций:
memchr, memcmp, memcpy, memset, strncat, strchr, strncmp, strncpy, strcspn, strerror, strlen, strpbrk, strrchr, strstr, strtok
— все с префиксом s21_.

### 2. sprintf (частичная реализация)

Поддерживаемые элементы:
- Спецификаторы: c, d, f, s, u, %
- Флаги: -, +, пробел
- Ширина: число
- Точность: .число
- Длина: h, l

### 3. Дополнительные модификаторы sprintf

Поддерживаются:
- Доп. спецификаторы: g, G, e, E, x, X, o, p
- Доп. флаги: #, 0
- Ширина/точность через *
- Длина: L

### 4. Специальные функции обработки строк

Реализованы дополнительно:
- s21_to_upper
- s21_to_lower
- s21_insert
- s21_trim

## Тестирование
 - Для всех функций написаны unit-тесты на базе библиотеки Check
 - Результаты сравниваются с аналогами из стандартной string.h
 - Обеспечено покрытие не менее 80% для каждой функции
 - Генерация HTML-отчёта покрытия с помощью gcov/lcov
